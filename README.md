# sudoku

Sudoku in the browser: unique puzzles from a seeded generator, box size 2–5 (4×4 up to 25×25), timer, undo/redo, and the game saved in your browser.

Play: https://bborbe.github.io/sudoku/

Built with Vite + TypeScript, no framework. See `AGENTS.md` for commands and layout.
